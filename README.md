# 卡厄思梦境 · 伤害计算器

基于《卡厄思梦境》代码层面的伤害公式，构建的浏览器端伤害计算器。

## 起因

NGA 玩家社区发布了一篇从代码层面分析《卡厄思梦境》伤害机制的超硬核帖子（[tid=46932958](https://bbs.nga.cn/read.php?tid=46932958)），详细拆解了属性计算、伤害公式、DVA修饰、护盾/治愈等全部底层逻辑。本项目将这些公式转化为可交互的计算工具，方便玩家快速验证和优化自己的配置。

## 功能

### 基础模式
输入最终 ATK、暴击率、暴伤等参数，一键计算非暴击/暴击/期望伤害，并展示完整的计算过程。

### 进阶模式
从角色基础属性开始，经过局外加成（装备/记忆碎片/伙伴）→ 局内加成（战斗buff）→ 最终伤害，走完整计算链。支持基于防御的混合伤害类型。

### 最优分析（三个子功能）

- **暴击曲面图**：暴击率 × 暴伤的 3D 期望伤害曲面（Plotly.js），可视化最优点
- **有限资源分配**：给定可分配属性点，计算暴击率 vs 暴伤的最优分配比例
- **装备词条优化**：模拟游戏记忆碎片系统，主词条二选一 + 副词条强化分配，含蒙特卡洛随机模拟

### 蒙特卡洛模拟
随机模拟 N 次攻击（1000~1000000 次），统计暴击分布、平均伤害、百分位数，支持随机种子复现。

### 配置对比
保存/加载两套配置到 localStorage，对比不同方案的伤害差异。

## 伤害公式

基于 NGA 帖子的代码分析：

```
最终伤害 = floor(
  eff_value × 值类型变换 × PS倍率 × DVA修饰 × 暴击判定
  × (ATK ÷ 100)
  × 0.36
  × (1 + 属性颜色加成%)
  × (1 + 追加攻击修正%)
)
→ 护盾吸收 → 免伤/减伤/分担被动 → HP扣除
```

属性计算：
```
最终属性 = round( round((基础值 × (1 + 局外百分比%) + 局外固定) × (1 + 局内计算%)) × (1 + 局内百分比%) + 局内固定 )
```

## 使用方式

1. 克隆仓库
```bash
git clone https://github.com/AsukaNemu/czn_damage.git
cd czn_damage
```

2. 启动本地服务器（ES Module 需要 HTTP 服务）
```bash
python3 -m http.server 8080
```

3. 打开浏览器访问 `http://localhost:8080`

无需安装任何依赖，纯静态页面。

## 游戏默认值

| 属性 | 默认值 |
|------|--------|
| 角色基础暴击率 | 3% |
| 角色基础暴伤 | 125% |
| 全局伤害修正系数 | 0.36 |
| 全局护盾修正系数 | 0.3 |
| 记忆碎片暴击率主词条 | +27% |
| 记忆碎片暴伤主词条 | +40.8% |
| 副词条暴击率范围 | 1.2% ~ 2.0% |
| 副词条暴伤范围 | 2.4% ~ 4.0% |
